# 报告与证据字段

每份报告写明run_id、北京时间起止、状态和实际代码提交/dirty diff/驱动SHA，引用用户确认的27轮拓扑、b/queue、闭环方法及输入范围。

逐轮表至少包含：接口、I、每实例W、实际总模型worker、C、b/queue、预热/正式/timeout、请求数、窗口内成功完成/最终成功、429/503/其他HTTP/业务/传输失败、窗口结束在途/排空、成功TPS、成功P50/P95/P99/均值、失败延迟、实际worker请求分布、全worker与发生器CPU/RSS、GPU显存/利用率/温度/功耗、可用主机内存和启动/清理状态。

列出模型/Engine/manifest/配置及池SHA、图片覆盖/频次、版本/设备证明、所有原始记录位置与逐文件指纹、资源采样是否仅正式窗口。内核时间、接口总耗时与排队不能混称；HTTP200需业务成功字段，429快速RPS不作处理能力。

每接口提供成功TPS-并发、成功P95/P99-并发、拒绝比例、资源曲线；逐拓扑列C50→100→200增幅和边际代价。明确一次测量、未穷尽C<50或>200、发生器/HTTP调度限制、其他CPU非独占、无生产SLO/准确率标注；区分实测、推断与未确定。

异常逐项记录首次时间、可达异常链/已有errno、逐worker日志、根因已证/未证、是否影响后续轮和处置。包记录字节数/SHA、源前后不变、本机整包/成员/解包校验。建议配置仅列本次有限窗口零失败且资源/计数完整的点；含拒绝/传输失败点保留但不推荐为零失败容量。
