## 实验完成与部署采用分别判断

- **实验完成**：约定范围内的测试、对照和报告齐备，即使 TensorRT 没有收益，也可以得出完整结论。
- **部署采用**：另外要求精度、延迟、失败率、稳定性及维护成本满足已冻结的业务门槛。未满足时保留 PyTorch FP16，不为了结项强行替换后端。
- **有限结论**：缺少人工标注时可以完成基线一致性对照，但真实准确率结论标为待评估；缺少 SLO 时可以完成容量曲线，但生产可用容量标为待确定。不能把这些状态写成全部验收通过。

性能和精度门槛在 TensorRT 正式验收前确定，不能看到结果后倒推门槛。实验结项不自动授权上线、合并或删除旧环境。
