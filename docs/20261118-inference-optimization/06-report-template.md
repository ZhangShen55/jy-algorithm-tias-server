# 单轮报告与最终对照模板

## 实验身份

- run_id、时间、执行人、测试目的：
- commit/差异、环境清单哈希、配置哈希、模型/引擎哈希：
- dataset_id/哈希、接口、输入方式、ROI、阈值、shape、batch：
- 后端、FP16 验证证据、GPU UUID、驱动/runtime：
- 实例数 I、总并发 C 或到达速率、每实例 worker 数：
- 分发策略、客户端位置、连接池、超时、重试、保护上限：
- 预热、采样时间、重复轮次、资源采样频率：

## 撞墙与容量

- 拐点判定规则、相邻配置、吞吐增益及延迟变化：
- 硬失败点、错误原因、日志位置：

- 满足 SLO 的容量；SLO 未确定时标为待定：

- PyTorch baseline_id，匹配参数，评估样本/排除样本数量：
- 各类别检测差异、计数误差、教师聚合差异：
- 人工标注指标（无标注则写不可评价）：
- 差异图片、原始结果、可视化路径及复核结论：

## 证据目录

```text

report.md                # 本轮解释与限制
```

## 最终决策

分别给出三接口 PyTorch FP16 与 TensorRT FP16 的同配置收益、各自最佳容量、精度变化、部署成本和推荐设置。说明是否有证据支持下一阶段 C++ 改造。
