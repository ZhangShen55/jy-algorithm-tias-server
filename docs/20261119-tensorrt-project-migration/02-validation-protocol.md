# 验证协议

本协议为建议冻结方法，待方案批准后执行。比较以旧 TRT 路径为迁移主对照，PT 为历史一致性参照，不把迁移目录的收益重新计为后端加速。

## 验证矩阵与判定

| 项目 | 执行方法 | 通过条件 |
|---|---|---|
| 四模型产物 | 全部文件 SHA、类别、shape、实际 backend、I/O dtype、批次检查；逐模型真实 warmup | 4/4 加载 TensorRT，I/O HALF，batch1，类别映射及哈希与受审产物一致 |
| 启动反例 | 缺任一 engine、哈希不符、缺依赖、错误设备、反序列化失败、FP32 I/O、错误 shape；分别独立运行 | 全部明确失败且不加载 .pt、不落 CPU、不在半初始化状态接收服务 |
| 三接口完整池 | Sync2162、学生2162、教师1577，共5901条；同一数据清单、FP16、相同配置、trace off、HTTP60秒、无重试 | HTTP/业务零失败；与同 Engine 旧 TRT 路径规范化最终响应逐项相等，所有差异留存并阻塞通过 |
| 业务对照 | 原完整池、ROI/阈值覆盖、Base64/data URL/本地路径/受控 loopback URL、损坏及缺失输入 | 公共路径/schema/状态和业务处理不变；错误输入返回既定错误，不崩溃或泄漏 |
| 几何覆盖 | 横图、竖图、非1920×1080、空/多 ROI、教师尺寸覆盖，固定图像 SHA；实施前冻结专门样本清单 | padding/缩放/坐标还原正确；同形状旧 TRT 对照相等；与旧 PT 几何差异独立记录 |
| 同接口并发 | 沿用已验证候选：TRT人数I8/C16/b2、学生I2/C8/b4、教师I8/C16/b2，各完整池一次 | 同后端最终业务一致、零失败，全部实例和负载进程回收 |
| 混合接口共享 | 一个 worker、三个接口轮流调用快速回归集各64图，再并发总C3重复3轮；seed20261118 | 对独立顺序 TRT 参考规范化一致，无参数串扰/错误/死锁；不能以原同接口审计代替 |
| 有限性能回归 | 三接口各I1/C1/b1，旧TRT→新TRT，新TRT→旧TRT，旧TRT→新TRT，seed20261118，预热30秒/发送300秒，trace off | 每轮零失败；逐对吞吐、延迟/资源完整报告；不新增事后百分比门槛 |
| 稳定性 | 新版每接口I1/C1/b1闭环30分钟，HTTP60秒 | 有限窗口零失败，无明显持续内存增长；并非生产SLO结论 |
| 保护回归 | 四engine加密/解密、错密钥/篡改/缺件、加载成功/异常清理；在独立私有临时目录运行 | 既有保护路径不退化、失败不残留明文，不改生产密钥/挂载 |
| 项目直接启动 | 在vbas-trt中从项目根和其他cwd分别启动新实例，关闭外部注册，独立测试端口；验证Health/WorkerStatus/Drain和重启 | 仅加载项目model四Engine、三接口可用、启动失败无半就绪、测试实例全部回收 |
| 旧版本恢复 | 独立测试端口恢复旧代码/环境/配置与权重，三接口快速64图各一次 | 回退完整通过，不涉及线上切换 |

规范化只去 TimeStamp、UseTimeMs、FreeCapacity 等已约定动态字段，并按历史规则排序；不取整浮点或删异常。模型原始输出数值检查 NaN/Inf、类别、置信度、框序和边界，完整记录对 PT 的既有差异。

固定 shape 的 batch1 不等于 HTTP 请求只能含一张，也不等于 MaxConcurrentBatches=1；现有业务逐图处理及准入语义必须保留。教师 ImageSize 请求/配置覆盖与静态 engine 不兼容时，在实施前列明受支持语义，不能偷偷忽略或新增 API 拒绝行为来通过测试。

## 保护与停止

每轮检查 GPU UUID、空闲和原主机预算8+I×1.5GiB；不与旧42轮或其他 GPU 任务重叠，不借用其他 GPU。保留完整请求、服务日志、资源、配置、启动/清理事件。出现未知错误、业务差异或几何回归先保存并停止，调查后修改实现；复验用新 run_id，不覆盖或重跑求通过。性能差异需解释但无预设生产SLO，用户决定有限结论是否满足试用目标。
