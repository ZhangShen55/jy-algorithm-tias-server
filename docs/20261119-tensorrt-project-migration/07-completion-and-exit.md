# 完成、退出与交接

## 当前状态

本轮实施中，四Engine在项目model/、实际GPU加载以及各模型100张对比/备份已完成；仍有HTTP、并发、稳定性和恢复出口未完成。TensorRT 已有性能优势是选择路线的依据，不代表项目交付迁移已完成；旧优化任务亦不因取消定时器自动结项。

## 阶段出口

1. 方案出口：八文件职责齐全，model目录已确认为项目根model/且不部署，用户评审TRT-only推理、保留必要torch依赖及整版回退的设计。
2. 产物出口：四Engine和manifest全件核验、来源可信、FP16/shape/类别正确、旧资产备份，缺件/错件启动明确失败。
3. 模型一致性出口：四模型各100张（400个模型-图片配对）PT FP16对实际Engine的检测输出对比完成；人数同100张另检True/False两种NMS。按02冻结清单、零运行失败、数值合法、逐框/逐类与计数差异及私有图齐备、完整备份本机核验。用户复核差异后决定采用；无标注不称真实准确率通过。
4. 功能出口：02的全量5901、几何/输入方式、并发与混合共享状态检查通过；与同Engine旧TRT业务响应一致；PT已有差异继续保留并交用户复核。
5. 服务端出口：项目model四Engine可直接加载，独立端口完成启动/重启/健康/排空、双worker及保护回归；旧版本恢复验证通过。Docker、容器重建与生产部署均未执行，不作为本轮完成条件。
6. 性能出口：三接口同配置有限配对/稳定性零失败，完整披露延迟和资源；无生产SLO不写生产容量验收，也不把已有+50%～77%结果当新打包版本的保证。
7. 工作完成：05全部获证据，06报告和整包/逐文件本机核验齐备，交接明确。是否采用与部署由用户另行决定。

## 停止与恢复

发现未知加载/推理失败、同TRT业务差异、参数串扰、几何语义变化、设备或版本不符、secure清理异常，保存现场并阻塞相关阶段。优先复用已有受审Engine和依赖；无法保持业务行为或需要扩大目标硬件/更换算法时向用户说明选择，不自动启用动态shape、新NMS或C++。不无限调参、不放宽队列/阈值/超时求通过。待修复或范围明确后新run_id复验，旧证据保留。
