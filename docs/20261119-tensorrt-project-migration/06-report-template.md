# 报告与证据规范

每次执行创建 reports/YYYYMMDD-阶段/<run_id>/report.md，使用中文；原始私有数据在独立产物存储。不得把下列字段留空后称阶段完成。

## 必需字段

| 分类 | 必填内容 |
|---|---|
| 标识 | run_id、北京时间起止、执行人、阶段、成功/失败/阻塞状态 |
| 关联 | commit、tracked diff、数据/配置/manifest/Engine/源权重SHA、参考run_id |
| 环境 | OS、Python和完整依赖、镜像digest、GPU UUID/型号、driver/CUDA/TensorRT版本 |
| 执行 | 精确命令、cwd、设备环境、I/C/b、seed、预热/正式/超时、保护配置 |
| 完整性 | 计划/已发/完成/成功/失败/本地未发、图片ID/SHA/序号覆盖、清理状态 |
| 业务 | backend/FP16/shape/类别证明、全量响应比较、计数差异、框/置信度变化、异常样本 |
| 模型100张对照 | 每模型100行清单及SHA、80随机/20历史差异分层、各类正例覆盖、两端框数、匹配/新增/缺失、IoU与置信度/坐标误差、计数差异和私有叠框图索引；人数两种NMS分开；对比完成/用户差异复核状态分开 |
| 性能 | 窗口定义、吞吐、P50/P95/P99/均值、各进程CPU/RSS、GPU显存/利用率、启动warmup和构建成本 |
| 交付 | 项目直接启动、独立端口、保护回归、双worker、重启、旧版本恢复记录；本轮部署标记未执行 |
| 异常 | 首次发生时间、已有异常链/errno、日志关联、根因已证明或未证明、处置和残余限制 |
| 备份 | 私有目录、包字节数/SHA、逐文件清单、封存前后源指纹、本机验证结果 |
| 结论 | 已验证范围、未验证范围、是否允许下一阶段、是否推荐试用、用户采用决定单列 |

含并行或嵌套span不相加；正式窗口与warmup资源分开，不平均P95冒充原始合并分位数。截图/图表仅展示脱敏汇总；照片、完整配置/响应/日志不提交Git。
